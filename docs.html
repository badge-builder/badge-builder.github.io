Use badge-builder in your project.

Generate compact SVG badges with JavaScript. Start with a simple status badge, then customize its shape, CSS, colors, icons, and background as your design needs grow.

npm install badge-builder

Quick start

The classic API is ideal for a two-part status badge. createBadge returns an SVG string and has no runtime dependencies.

JavaScript

Label and message

Choose a label, message, and a built-in status color. You can also use any 3- or 6-digit hex color.

import { createBadge } from "badge-builder";

const svg = createBadge({
  label: "build",
  message: "passing",
  color: "success"
});

Render it with your page CSS

The SVG has intrinsic dimensions. Style its containing element or set a display width on the generated SVG to fit your layout.

CSS + JavaScript

Size and align the badge

Render package-generated SVG into a dedicated element. The example uses innerHTML only for the trusted string returned by this library.

For untrusted text or user-created SVG, do not insert arbitrary markup into innerHTML.

/* Your app stylesheet */
.badge-slot {
  display: inline-flex;
  align-items: center;
  max-width: 100%;
}

.badge-slot svg {
  display: block;
  width: 220px;
  max-width: 100%;
  height: auto;
}

/* Your app JavaScript */
import { createBadge } from "badge-builder";

document.querySelector(".badge-slot").innerHTML =
  createBadge({ label: "coverage", message: "92%", color: "info" });

Blocks and shapes

Use one to six blocks when you want independent text and colors. Choose a silhouette with the shape option.

readysquare
readyrounded
readydots (pill)
✓circle
JavaScript

Compose multiple segments

Each block accepts text, a color, and optionally a text/emoji icon or a path-only SVG icon. Circle badges use a single short label or icon.

const svg = createBadge({
  blocks: [
    { text: "build", color: "#333" },
    { text: "passing", color: "success" },
    { text: "coverage", color: "info", icon: "✓" }
  ],
  shape: "dots"
});

// Other shapes: "square", "rounded", "circle"
const dot = createBadge({
  blocks: [{ text: "✓", color: "success" }],
  shape: "circle"
});

Gradients, borders, and text styling

Use built-in options for segment fills and outlines. customCss changes badge text only; it is validated against an allowlist and is not a general CSS injection point.

JavaScript

Apply a gradient and local font

The font-family is written into the SVG but not downloaded. If it is not available on the viewing device, its fallback is used.

const svg = createBadge({
  blocks: [
    { text: "release", color: "#333" },
    { text: "v2.0", color: "info" }
  ],
  gradient: {
    from: "#7c3aed",
    to: "#ec4899",
    direction: "horizontal",
    blockIndex: 1
  },
  borderColor: "#242424",
  borderWidth: 1,
  fontFamily: "Inter, sans-serif",
  fontSize: 12,
  customCss: "font-weight: 700; text-transform: uppercase"
});
Allowed text CSS

Keep text styles predictable

Only these declarations and bounded values are supported:

PropertyAllowed values
font-size8–18px
font-weightnormal, bold, or 100–900
font-stylenormal, italic, oblique
letter-spacingpx or em within a small range
text-transformnone, uppercase, lowercase, capitalize
text-decorationnone, underline, line-through
opacity0–1

Use a custom background image

Images are embedded into the SVG as base64 data, so the finished badge is self-contained. PNG, JPEG, and WebP files up to 512 KB are supported. External image URLs and SVG images are rejected.

Browser file input

Read a local image

Convert a user-selected file to a data URI, then pass it to backgroundImage. The library validates the data URI format and size.

File selection stays in the browser; this example does not upload the image to a server.

import { createBadge } from "badge-builder";

async function badgeWithImage(file) {
  const allowedTypes = ["image/png", "image/jpeg", "image/webp"];
  if (!allowedTypes.includes(file.type)) {
    throw new TypeError("Choose a PNG, JPEG, or WebP image");
  }
  if (file.size > 512 * 1024) {
    throw new RangeError("Image must be 512 KB or smaller");
  }

  const data = await new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.addEventListener("load", () => resolve(reader.result));
    reader.addEventListener("error", () => reject(reader.error));
    reader.readAsDataURL(file);
  });

  return createBadge({
    blocks: [{ text: "featured", color: "#333" }],
    backgroundImage: data
  });
}

const file = document.querySelector("#image").files[0];
if (file) {
  document.querySelector("#preview").innerHTML =
    await badgeWithImage(file);
}

Icons and animation

Icons can be short text/emoji or a path-only SVG object. Animation is opt-in and stops for users who request reduced motion.

JavaScript

Add a path icon or gentle pulse

Only SVG path data is accepted for vector icons—arbitrary SVG markup is intentionally not allowed.

const svg = createBadge({
  blocks: [{
    text: "ready",
    color: "success",
    icon: {
      path: "M12 2L2 22h20L12 2z",
      viewBox: "0 0 24 24"
    }
  }],
  animated: true
});

Download the SVG

Save the generated string directly as an SVG file in the browser or write it to disk in Node.js.

Browser

Download from the page

Create a temporary Blob URL, trigger a download, then release the URL.

const svg = createBadge({
  label: "build",
  message: "passing",
  color: "success"
});

const url = URL.createObjectURL(
  new Blob([svg], { type: "image/svg+xml" })
);
const link = document.createElement("a");
link.href = url;
link.download = "build-status.svg";
link.click();
URL.revokeObjectURL(url);
Node.js

Write it to disk

The returned SVG can be stored, served as a static file, or included in generated documentation.

import { writeFile } from "node:fs/promises";
import { createBadge } from "badge-builder";

const svg = createBadge({
  label: "tests",
  message: "passing",
  color: "success",
  shape: "rounded"
});

await writeFile("tests.svg", svg, "utf8");

API reference

All options are optional except the classic label/message pair or the blocks array. Invalid values throw a descriptive TypeError.

OptionTypeDescription
label, messagestringRequired for the classic two-segment badge form.
colorstatus or hexMessage color: success, error/failure, warning, info, neutral, or #RGB/#RRGGBB.
blocksarrayOne to six objects with text, optional color, and optional icon.
shapestringrounded (default), square, dots (pill), or circle (one short block).
gradientobjectfrom/to colors, optional direction and blockIndex; defaults to the last block.
borderColorhexOptional outline color; enable it with any valid hex value.
borderWidthnumberOutline width from 0 to 4; defaults to 1 when a border color is set.
fontFamily, fontSizestring, numberLocal font family list and 8–14px font size. No remote font is loaded.
customCssstringValidated text-only CSS declarations from the allowlist above.
backgroundImagedata URIEmbedded PNG, JPEG, or WebP image up to 512 KB; last block by default.
animatedbooleanEnable a reduced-motion-aware opacity pulse.

HTTP API

The Worker in worker/src/index.js serves the same badges over HTTP. Responses are image/svg+xml with CORS enabled and edge caching, so a badge URL can be embedded directly in Markdown or HTML.

Markdown / HTML

Request or embed a badge

Use the query form or the /badge/:label/:message shorthand. Complex options such as blocks and gradient are URL-encoded JSON.

https://<worker-host>/badge?label=build&message=passing&color=success

https://<worker-host>/badge/build/passing?color=success&shape=dots

<img src="https://<worker-host>/badge/build/passing?color=success"
     alt="build: passing">
ParameterDescription
label, message, colorClassic two-part badge. Required unless blocks is present.
blocksURL-encoded JSON array of { text, color?, icon? } objects, same as the JavaScript API.
shaperounded, square, dots, or circle.
gradientURL-encoded JSON { from, to, direction?, blockIndex? }.
fontFamily, fontSizeLocal font list and 8–14px size.
borderColor, borderWidthOutline color and 0–4 width.
animated, customCssReduced-motion-aware pulse and allowlisted text declarations.
Deploy

Run it on Cloudflare Workers

Deploy from the worker/ directory; Wrangler bundles the library into the Worker. Use Wrangler or the Cloudflare dashboard to attach a custom domain.

Invalid input returns a JSON error with a 400 status. HEAD is supported, other methods return 405, and backgroundImage is not accepted over HTTP.

cd worker
npm install
npm run dev

# After signing in with: npx wrangler login
npm run deploy
